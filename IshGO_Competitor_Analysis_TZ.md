# Конкурентный анализ IshGO (ishgo.uz) и ТЗ на улучшение Verifix Jobs

**Дата:** 24 марта 2026
**Автор:** Claude Code (автоматический анализ)
**Объект:** ishgo.uz — платформа по поиску работы и найму в Узбекистане
**Цель:** Выявить сильные/слабые стороны конкурента, разработать рекомендации для Verifix Jobs

---

## 1. Анализ конкурента IshGO

### 1.1 Общая информация
- **URL:** ishgo.uz
- **Позиционирование:** Job-портал для blue-collar и office-позиций в Узбекистане
- **Статистика (на момент анализа):** 25,200+ резюме, 2,130+ вакансий, 200+ компаний
- **Мобильные приложения:** Google Play + App Store
- **Язык интерфейса:** Узбекский (латиница), с переключателем
- **Связь с ATS:** Интеграция с Jobster.hr (ATS-система)
- **Telegram:** Канал с вакансиями + кнопка Telegram-бота на каждой странице

### 1.2 Сильные стороны

#### S1. Трёхколоночная desktop-архитектура (Split-View)
- **Левая колонка:** Навигация + профиль компании + разделы работодателя
- **Центральная:** Список вакансий/кандидатов/компаний
- **Правая:** Детальная информация (при клике на вакансию открывается справа, без перехода на другую страницу) + блок статистики + топ-компании
- **Преимущество:** Пользователь не теряет контекст списка при просмотре деталей

#### S2. Единая навигация для работодателя и соискателя
Левое меню объединяет:
- Публичные разделы: Vakansiyalar, Sohalar, Korxonalar, Ish izlovchilar
- Работодательские: Mening vakansiyalarim, Tanlanganlar, Ishga topshirgan nomzodlar, Nomzodlarga takliflar, Bildirishnomalar
- Профиль компании (Vulkan CO)
- Интеграция с ATS (Jobster'ga qo'shilish)

#### S3. Простой и эффективный ATS-пайплайн
- Раздел "Ishga topshirgan nomzodlar" (Откликнувшиеся кандидаты):
  - 3 стадии: **Yangi** (Новые) → **Jarayonda** (В процессе) → **Suhbat** (Собеседование)
  - Фильтр по вакансиям
  - Архив отклонённых
- Раздел "Nomzodlarga takliflar" — отправленные приглашения кандидатам

#### S4. Статусная система вакансий
- 4 таба: **Tekshiruvda** (На модерации) → **Faol** (Активные) → **Arxiv** (Архив) → **Rad etilgan** (Отклонённые)
- Счётчики: просмотры (53), кандидаты (11)
- Контекстное меню (три точки) для быстрых действий

#### S5. Система "TOP" вакансий
- Платное продвижение: оранжевый бейдж "TOP ⭐" на карточке
- Верхние позиции в листинге
- Визуально выделяются на фоне обычных

#### S6. Верифицированные компании
- Синий значок ✅ рядом с названием компании
- Повышает доверие соискателей

#### S7. Каталог отраслей (Sohalar) с метриками
- Каждая отрасль показывает: количество вакансий + количество компаний
- Категории: Savdo va tijorat (851), Restoran va Fast food (529), Ma'muriy xodimlar (255), Ishchi xodimlar va Servis (128), Transport (87), Go'zallik va Fitness (80), Logistika va Ombor (77), Ilm va Ta'lim (54), Tozalash va Klining и др.

#### S8. Каталог компаний (Korxonalar)
- Логотип, название, отрасль, количество вакансий
- Сортировка по количеству вакансий
- Топ: Safia (477), Audiotele (250), Oqtepa Lavash (222), B&B (115)

#### S9. База соискателей для работодателей (Ish izlovchilar)
- 25,242 резюме
- Карточка: должность, статус ("Faol ish izlayabman"), локация, возраст
- Кнопка избранного (сердечко)
- Поиск + фильтры + сортировка

#### S10. Детальная карточка вакансии
- Табы: Ish tavsifi (Описание) | Korxona haqida (О компании) | Boshqa vakansiyalar (Другие вакансии)
- Поля: Soha, Lavozim, Bandlik turi, Ishchilar soni, Hudud
- Структурированное описание: Majburiyatlar (Обязанности), Talablar (Требования), Shartlar (Условия)
- Счётчик просмотров (288)
- Ссылка на Telegram-канал

#### S11. Профиль компании (работодатель)
- Поля: Отрасль, Количество сотрудников, Тип компании, ИНН (STIR), Телефон (с toggle видимости), Telegram, Веб-сайт, Email, Регион/Район, Адрес
- WYSIWYG-редактор для описания компании
- Геолокация (кнопка определения)
- Загрузка логотипа

#### S12. Уведомления
- "Kunlik hisobot" — ежедневный отчёт по активности
- Бейдж со счётчиком (1) в навигации

#### S13. Мультиязычность
- Переключатель O'zb (узбекский латиница)
- Интерфейс локализован

#### S14. Правая боковая панель со статистикой
- Платформенные метрики: 25,200+ резюме, 2,130+ вакансий, 200+ компаний
- Топ-компании с логотипами и количеством вакансий
- Ссылки на мобильные приложения (Google Play, App Store)

### 1.3 Слабые стороны

#### W1. Отсутствие геолокационного поиска
- Нет поиска "рядом со мной"
- Нет карты вакансий
- Нет расчёта расстояния до работы
- Только текстовый фильтр по региону (O'zbekiston)

#### W2. Ограниченная система фильтрации
- Всего 4 фильтра: Maosh (зарплата), Ish turi (тип работы), Bandlik turi (тип занятости), Ish tajribasi (опыт)
- Нет фильтра по графику/сменам
- Нет фильтра по бенефитам (еда, транспорт, медицина)
- Нет фильтра по расстоянию

#### W3. Нет визуальных бенефитов на карточках вакансий
- Карточка вакансии показывает только: название, зарплату, компанию, тип занятости, дату
- Нет иконок бенефитов (еда, транспорт, медицина)
- Нет информации о графике/сменах на карточке

#### W4. Отсутствие salary highlight на карточках
- Зарплата есть, но "Kelishiladi" (Договорная) — у многих вакансий
- Нет визуального выделения зарплаты как конкурентного преимущества
- Нет сравнения с рыночной зарплатой

#### W5. Примитивный ATS без Kanban
- Только 3 стадии (Yangi, Jarayonda, Suhbat) — линейный список, не Kanban
- Нет drag-and-drop
- Нет bulk-действий
- Нет интервью-шедулинга
- Нет командных заметок

#### W6. Нет аналитики для работодателей
- Только базовые счётчики просмотров
- Нет воронки найма
- Нет метрик time-to-hire
- Нет сравнения по вакансиям

#### W7. Нет реферальной системы
- Нет механизма рекомендаций друзей
- Нет вирального loop для роста базы кандидатов

#### W8. Нет интеграции с государственными системами
- Нет синхронизации с ARGOS, ish.mehnat.uz
- Нет gov-отчётности

#### W9. Нет системы подписок/монетизации (видимой)
- Единственная видимая монетизация — TOP-размещение вакансий
- Нет тарифных планов
- Нет branding-страниц компаний

#### W10. Нет MyID/KYC верификации
- Верификация компаний непрозрачна
- Нет верификации кандидатов

#### W11. Слабая мобильная веб-версия
- На мобильном viewport layout не адаптируется (3-колоночный layout сохраняется)
- Полагаются на нативные приложения

#### W12. SEO — слабая оптимизация
- URL-ы: ishgo.uz/vacancies/oqtepa-lavash-barmen-0003541 (OK, но нет города в URL)
- Нет JSON-LD JobPosting разметки (не видно)
- Нет посадочных страниц по городам/категориям

#### W13. Смешение языков
- Названия вакансий на русском ("Производитель сырья и продукции"), интерфейс на узбекском
- Нет автоматического определения языка
- Нет параллельного отображения на двух языках

#### W14. Нет AI/ML функций
- Нет рекомендаций вакансий
- Нет matching-скоринга
- Нет salary prediction
- Нет fraud detection

### 1.4 Уникальные особенности IshGO

| Фича | Описание | Есть в Verifix Jobs ТЗ? |
|-------|----------|------------------------|
| Split-View (3 колонки) | Детали вакансии справа без перехода | Нет (отдельная страница) |
| TOP-размещение | Платное продвижение с бейджем | Нет |
| Jobster ATS интеграция | Ссылка на внешний ATS | Встроенный ATS (лучше) |
| Ежедневный отчёт | Kunlik hisobot в уведомлениях | Есть (Digest) |
| Статистика на sidebar | Метрики платформы + топ компании | Нет |
| Каталог отраслей | Отдельная страница с метриками | Нет (только фильтр) |

## 2. Рекомендации по улучшению Verifix Jobs

### Приоритет 1 (Критично — реализовать до запуска)

#### P1-01. Split-View layout для списка вакансий
- **Описание:** При клике на вакансию в списке — детали открываются в правой панели, список остаётся слева
- **Обоснование:** IshGO использует этот паттерн, это стандарт для email-клиентов и job-бордов (LinkedIn, Indeed). Пользователь просматривает 10-20 вакансий — переходы на отдельные страницы убивают конверсию
- **Ожидаемый результат:** +30-40% к времени на сайте, +20% к количеству просмотренных вакансий
- **Реализация:** Angular CDK, resizable panels, route params для deep-linking

#### P1-02. Система TOP/промо-размещения вакансий
- **Описание:** Платное продвижение вакансий с визуальным выделением (бейдж, верхние позиции, подсветка)
- **Обоснование:** У IshGO это основной канал монетизации. Для Verifix Jobs это дополнительный revenue stream помимо подписок
- **Ожидаемый результат:** +15-20% к MRR за счёт разовых промо-платежей
- **Варианты:** TOP (7 дней) — 200,000 UZS, Premium (14 дней) — 350,000 UZS, VIP (30 дней) — 500,000 UZS

#### P1-03. Каталог отраслей (Sohalar) как отдельный раздел
- **Описание:** Страница с категориями работ: иконка, название, количество вакансий, количество компаний
- **Обоснование:** IshGO имеет этот раздел, и он помогает blue-collar кандидатам, которые не знают точного названия должности, но знают отрасль
- **Ожидаемый результат:** Улучшение навигации для low-literacy пользователей, SEO-выгода от посадочных страниц по категориям
- **Реализация:** Использовать существующую таблицу категорий, создать landing-page /categories/{slug}

#### P1-04. Правая sidebar со статистикой и топ-компаниями
- **Описание:** Блок справа на desktop: метрики платформы (количество резюме, вакансий, компаний), топ-компании с логотипами, ссылки на приложения
- **Обоснование:** Social proof — показывает масштаб платформы. IshGO использует это эффективно. Для нового сервиса это критично для доверия
- **Ожидаемый результат:** +10-15% к конверсии регистрации работодателей

### Приоритет 2 (Важно — Sprint 2-3)

#### P2-01. Расширенная карточка вакансии с бенефитами
- **Описание:** На карточке вакансии в списке показывать: иконки бенефитов (еда, транспорт, медицина), график смен, расстояние от кандидата
- **Обоснование:** IshGO НЕ делает этого — это наше конкурентное преимущество. Для blue-collar бенефиты часто важнее зарплаты
- **Ожидаемый результат:** +25% к CTR на вакансии с указанными бенефитами

#### P2-02. Каталог компаний с branding-страницами
- **Описание:** Раздел /companies с карточками: логотип, название, отрасль, количество вакансий, верификация. Клик — branding-страница (уже в ТЗ Employer Branding)
- **Обоснование:** IshGO имеет базовый каталог компаний. Verifix Jobs с branding-страницами будет значительно лучше
- **Ожидаемый результат:** Монетизация через Premium Branding (1,990,000 UZS/мес)

#### P2-03. Улучшенная фильтрация вакансий
- **Описание:** Помимо базовых фильтров (зарплата, тип, опыт), добавить:
  - По расстоянию (1/3/5/10/20 км) — **уникально vs IshGO**
  - По бенефитам (еда, транспорт, жильё) — **уникально vs IshGO**
  - По графику (5/2, 2/2, 6/1, гибкий) — **уникально vs IshGO**
  - По верификации компании
- **Обоснование:** IshGO имеет только 4 базовых фильтра. Расширенные фильтры — сильное конкурентное преимущество
- **Ожидаемый результат:** +20% к релевантности результатов, снижение bounce rate

#### P2-04. Kanban ATS-пайплайн (вместо линейного списка)
- **Описание:** Визуальная доска: NEW → SHORTLIST → INVITED → INTERVIEW → OFFER → HIRED + REJECTED. Drag-and-drop. Desktop: Kanban, Mobile: swipe-карточки
- **Обоснование:** IshGO имеет только 3-стадийный линейный список. Полноценный Kanban — конкурентное преимущество для mass-hiring HR
- **Ожидаемый результат:** -40% времени на обработку кандидатов

#### P2-05. Аналитика для работодателей
- **Описание:** Дашборд: воронка найма, source attribution, time-to-hire, cost-per-hire, сравнение вакансий
- **Обоснование:** IshGO не имеет аналитики — только счётчики просмотров. Это сильный аргумент для Premium-подписки
- **Ожидаемый результат:** Конверсия в платные тарифы +30%

#### P2-06. Геолокационный поиск "Работа рядом"
- **Описание:** Кнопка "Yaqindagi ishlar" (Работа рядом) — запрашивает геолокацию, показывает вакансии на карте с расстоянием
- **Обоснование:** IshGO полностью отсутствует геопоиск. Для blue-collar расстояние до работы — фактор #1 после зарплаты
- **Ожидаемый результат:** +35% к релевантности для mobile-пользователей

### Приоритет 3 (Желательно — Phase 2+)

#### P3-01. Salary Intelligence
- **Описание:** Показывать рыночный диапазон зарплат для позиции+города. На карточке вакансии: "Выше рынка ↑", "На уровне рынка →", "Ниже рынка ↓"
- **Обоснование:** IshGO не имеет. Привлекает и кандидатов (понимают рынок), и работодателей (видят бенчмарки)

#### P3-02. AI-рекомендации вакансий
- **Описание:** "Рекомендуем для вас" — блок с персонализированными вакансиями на основе профиля, истории просмотров, откликов
- **Обоснование:** IshGO не имеет никакого ML/AI

#### P3-03. Реферальная leaderboard-страница
- **Описание:** Публичный рейтинг топ-рефереров с наградами. Интеграция в Telegram Mini App
- **Обоснование:** IshGO не имеет реферальной системы — это viral growth engine

#### P3-04. Интеграция с gov-системами
- **Описание:** Автопубликация в ARGOS/ish.mehnat.uz, импорт государственных вакансий
- **Обоснование:** IshGO не имеет. Это compliance advantage + расширение базы вакансий

#### P3-05. Fraud detection и anti-spam
- **Описание:** Автоматическое обнаружение фейковых вакансий, дубликатов аккаунтов
- **Обоснование:** IshGO имеет модерацию, но без ML — правила ручные

## 3. Функциональные требования

### FR-01. Split-View Layout
| Параметр | Значение |
|----------|----------|
| **Описание** | 3-колоночный layout: навигация (240px) + список (flex) + детали (40%) |
| **Поведение Desktop (>1024px)** | При клике на вакансию — детали появляются в правой панели, список остаётся. URL обновляется через query param (?detail=vacancyId) |
| **Поведение Tablet (768-1024px)** | 2 колонки: список + детали overlay |
| **Поведение Mobile (<768px)** | Одна колонка: полноэкранная детальная страница с кнопкой "Назад" |
| **Анимация** | Slide-in справа, 200ms ease-out |
| **Обоснование** | Паттерн IshGO показал эффективность; стандарт LinkedIn/Indeed |
| **Ожидаемый результат** | +30% к просмотренным вакансиям за сессию |

### FR-02. TOP/Промо размещение вакансий
| Параметр | Значение |
|----------|----------|
| **Описание** | Работодатель может "продвинуть" вакансию за доп. плату |
| **Визуальное отличие** | Бейдж "TOP ⭐" (оранжевый), подсветка карточки (gradient border), приоритет в сортировке |
| **Тарифы** | TOP-7 (200K UZS), TOP-14 (350K UZS), TOP-30 (500K UZS) |
| **Оплата** | Click.uz / Payme.uz (уже в ТЗ) |
| **Позиционирование** | TOP-вакансии показываются первыми в категории, отмечены на карте |
| **Лимиты** | Не более 20% TOP-вакансий в выдаче (чтобы не обесценить) |
| **Обоснование** | Основная монетизация IshGO; дополняет подписочную модель Verifix |
| **Ожидаемый результат** | +15-20% к MRR |

### FR-03. Каталог отраслей
| Параметр | Значение |
|----------|----------|
| **Описание** | Страница /categories с плитками отраслей |
| **Каждая плитка** | Иконка (emoji/SVG), название (uz/ru), количество вакансий, количество компаний |
| **Поиск** | Текстовый поиск по названию категории |
| **Клик** | Переход на /vacancies?category={slug} — отфильтрованный список |
| **SEO** | Каждая категория — отдельная landing page с meta tags |
| **Категории** | Те же 12 из ТЗ: Qurilish, Savdo, Oshxona, Logistika, Ishlab chiqarish, Go'zallik, Ta'mirlash, Ombor, Tozalash, Haydovchi, Call Center, Boshqa |
| **Обоснование** | IshGO имеет; помогает low-literacy кандидатам |
| **Ожидаемый результат** | Улучшение навигации, SEO-трафик по категориям |

### FR-04. Статистический sidebar
| Параметр | Значение |
|----------|----------|
| **Описание** | Правая панель на desktop (300px fixed) |
| **Метрики** | Количество резюме, вакансий, компаний (обновляются ежедневно) |
| **Топ-компании** | 9 карточек (3x3 grid): логотип, название, количество вакансий. Клик → страница компании |
| **Mobile Apps** | Кнопки Google Play / App Store |
| **Поведение** | Sticky при скролле; скрывается на <1280px |
| **Обоснование** | Social proof по аналогии с IshGO |
| **Ожидаемый результат** | +10-15% к доверию новых пользователей |

### FR-05. Расширенные фильтры вакансий
| Параметр | Значение |
