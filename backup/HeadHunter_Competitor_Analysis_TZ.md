## 1. Анализ конкурента HeadHunter UZ

### 1.1 Общая информация
- **URL:** tashkent.hh.uz (+ региональные поддомены)
- **Позиционирование:** Универсальный job-портал #1 в Узбекистане (и СНГ)
- **База:** 6,573,580 резюме (на момент анализа)
- **Архив компании:** 292 архивных вакансии, 24 активных публикаций, 12 шаблонов
- **Язык:** Русский (основной) + узбекский в некоторых продуктах
- **Мобильное приложение:** Да (QR-код на сайте)
- **Монетизация:** Пакетная (публикации вакансий + доступ к базе резюме + продвижение)

### 1.2 Сильные стороны

#### S1. Масштаб базы резюме — 6.5M+
- Крупнейшая база кандидатов в Узбекистане
- Фильтры: Регион, Опыт в профессии, Статус поиска, Тип занятости, График работы, Общий опыт, Уровень дохода
- "Выберите вакансию → применим фильтры из неё" — AI-like подсказка
- Табы: Поиск по базе / Избранное / Автопоиск
- Бейджи на резюме: "Часто отвечает", "Активно ищет работу"

#### S2. Детальная таблица вакансий работодателя
- Колонки: Вакансия, Регион, Просмотры, Отклики (+новые), В работе, Резюме (количество подходящих в базе!), Истекает, Продвижение

- Табы: Активные (4), Черновики (0), Архив (292), Шаблоны (12)

### 1.3 Слабые стороны

#### W1. Ориентирован на white-collar
- Интерфейс и язык — для офисных работников с высокой цифровой грамотностью
- Резюме требует заполнения множества полей — barrier для blue-collar
- Нет Telegram-first подхода
- Основной язык — русский (blue-collar кандидаты часто говорят только на узбекском)

#### W2. Нет геолокационного поиска
- Только текстовый фильтр "Регион"
- Нет карты с вакансиями
- Нет расчёта расстояния до работы
- Нет "работа рядом"

#### W3. Дорого для малого бизнеса
- Базовые пакеты включают 10+ вакансий и сотни контактов
- Нет микро-тарифа "1 вакансия"
- Ценообразование ориентировано на средний и крупный бизнес

#### W4. Нет реферальной системы
- Нет вирального механизма роста через рекомендации
- Рост только через SEO + рекламу

#### W5. Нет интеграции с государственными системами
- Нет синхронизации с ARGOS / ish.mehnat.uz
- Нет gov-reporting

#### W6. Нет AI matching / scoring
- Поиск — keyword-based
- Нет AI score кандидатов
- "Подходящие резюме: 36892" — количество, но не качество

#### W7. Нет визуальных бенефитов
- Карточки вакансий не показывают бенефиты (еда, транспорт, медицина)
- Нет графика смен на карточке
- Информация доступна только в тексте вакансии

#### W8. Нет Telegram Bot / Mini App
- Только web + mobile app
- Blue-collar кандидаты предпочитают Telegram

#### W9. Нет MyID/KYC верификации
- Нет верификации кандидатов через государственный ID
- Нет визуального бейджа верификации

#### W10. UI перегружен для mass-hiring
- Десятки фильтров, сложная навигация
- Ориентирован на опытных HR-специалистов
- Не оптимизирован для быстрых решений при массовом найме

## 2. Рекомендации по улучшению Verifix Jobs

### Приоритет 1 (Критично)

#### P1-01. Индекс вежливости работодателя (Employer Response Index)
- **Описание:** Показатель скорости и полноты ответа работодателя на отклики кандидатов (0-100%)
- **Расчёт:** (Отклики с ответом в течение 48ч / Все отклики) × 100
- **Отображение:** На профиле компании, на карточке вакансии, на dashboard работодателя
- **Влияние:** Высокий индекс (>70%) → приоритет в выдаче + бейдж "Tez javob beradi" (Быстро отвечает)
- **Обоснование:** HH.uz показывает "21%" — это стимулирует работодателей не игнорировать отклики. Для blue-collar рынка это критически важно — кандидаты быстро теряют мотивацию
- **Ожидаемый результат:** +50% к response rate работодателей, -30% к churn кандидатов

#### P1-02. Автопоиск кандидатов (Saved Searches + Auto-notify)
- **Описание:** Работодатель сохраняет параметры поиска → система автоматически присылает новых подходящих кандидатов
- **Параметры:** Категория, город, зарплата, опыт, статус (ищет/не ищет), MyID верификация
- **Каналы уведомлений:** Email (веб-панель), Telegram bot (для HR), Push (PWA)
- **Частота:** Моментально (real-time match) или ежедневный дайджест
- **Обоснование:** HH.uz имеет "Автопоиск" — это killer feature для рекрутеров, особенно при mass-hiring
- **Ожидаемый результат:** -60% времени на проактивный поиск кандидатов

#### P1-03. Шаблоны вакансий
- **Описание:** Сохранение вакансии как шаблона для быстрого повторного использования
- **Функции:** Сохранить как шаблон, Создать из шаблона, Библиотека шаблонов (общие + пользовательские)
- **Предустановленные:** "Кассир", "Продавец", "Повар", "Водитель", "Грузчик", "Уборщик" — с типичными описаниями, требованиями, бенефитами
- **Обоснование:** HH.uz имеет 12 шаблонов у одного аккаунта. Для mass-hiring (Makro набирает кассиров в 20 филиалах) это must-have
- **Ожидаемый результат:** -70% времени на создание повторяющихся вакансий

#### P1-04. Колонка "Подходящие кандидаты" в таблице вакансий
- **Описание:** В таблице вакансий работодателя показывать количество подходящих кандидатов из базы
- **Расчёт:** Elasticsearch query по критериям вакансии (город + категория + зарплата) → COUNT
- **Визуализация:** "458 nomzod" рядом с кнопкой "Ko'rish" (Просмотреть)
- **Обоснование:** HH.uz показывает "Резюме: 36892" — это мотивирует работодателя активнее пользоваться базой
- **Ожидаемый результат:** +40% к конверсии в просмотр базы резюме

### Приоритет 2 (Важно)

#### P2-01. Пакетная монетизация (Bundle pricing)
- **Описание:** Комплексные пакеты вместо только подписок:
  - **Starter:** 3 вакансии + 50 просмотров резюме + 1 TOP (бесплатно)
  - **Business:** 10 вакансий + 200 просмотров + 3 TOP + аналитика (990K UZS/мес)
  - **Professional:** Unlimited + 500 просмотров + 10 TOP + branding + API (2.99M UZS/мес)
- **Спецпредложения (как у HH):** "Manfaatli 10-lik" — пакет с дисконтом
- **Обоснование:** HH.uz продаёт пакетами (вакансии + контакты + продвижение). Это увеличивает ARPU по сравнению с чистой подпиской

#### P2-02. "Поднять" вакансию (Bump/Refresh)
- **Описание:** Кнопка обновления даты вакансии → поднимается в выдаче поиска
- **Лимиты:** 1 бесплатный bump/вакансию/нед. Дополнительные: 50K UZS каждый
- **Визуализация:** "Yangilandi: bugun" (Обновлено: сегодня) на карточке
- **Обоснование:** HH.uz имеет кнопку "Поднять". Проще и дешевле чем TOP, даёт quick boost

#### P2-03. Автоматизация обработки откликов
- **Описание:** Настраиваемые правила auto-action:
  - "Если match score < 40% → автоотказ с стандартным сообщением"
  - "Если match score > 80% → автоприглашение на собеседование"
  - "Если нет ответа 48ч → напомнить HR"
- **Обоснование:** HH.uz имеет колонку "Автоматизация". Для mass-hiring с 200+ откликами это необходимо

#### P2-04. Бейджи активности кандидатов
- **Описание:** На карточке кандидата:
  - "Faol ish izlayabman" (Активно ищу работу) — зелёный
  - "Tez javob beradi" (Быстро отвечает) — синий
  - "MyID tasdiqlangan" (MyID подтверждён) — золотой
  - "Oxirgi faollik: bugun" (Последняя активность: сегодня)
- **Обоснование:** HH.uz показывает "Часто отвечает", "Активно ищет работу" — помогает рекрутерам приоритизировать

#### P2-05. Multi-manager аккаунт с ролями
- **Описание:** Несколько HR-менеджеров на одном аккаунте работодателя:
  - ADMIN — полный доступ + биллинг
  - RECRUITER — создание вакансий + просмотр откликов
  - VIEWER — только просмотр
- **Фильтр:** "Мои вакансии" / "Все вакансии" / "Менеджер: Анвар" (как у HH.uz)
- **Обоснование:** HH.uz имеет систему менеджеров. Для компаний с 3+ HR это критично

### Приоритет 3 (Желательно)

#### P3-01. Вебинары/Обучение для HR (контент-маркетинг)
- **Описание:** Раздел "Обучение" с вебинарами, статьями, гайдами для HR
- **Контент:** "Qanday qilib yaxshi vakansiya yozish", "Mass-hiring best practices", "Telegram orqali yollash"
- **Обоснование:** HH.uz имеет вебинары и сертификацию. Это positioning + SEO + retention

#### P3-02. Статистика рынка труда (Market Intelligence)
- **Описание:** Публичная аналитика: средние зарплаты по позициям, динамика вакансий по отраслям, конкуренция за кандидатов
- **Обоснование:** HH.uz публикует аналитику рынка. Это attracts работодателей + SEO

#### P3-03. Система рекомендаций вакансий для работодателя
- **Описание:** "Рекомендуем добавить фото офиса — вакансии с фото получают на 35% больше откликов"
- **Обоснование:** Аналог подсказок HH.uz для повышения качества вакансий

## 3. Функциональные требования

### FR-01. Employer Response Index
| Параметр | Значение |
|----------|----------|
| **Описание** | Показатель скорости ответа работодателя (0-100%) |
| **Формула** | (responses_within_48h / total_applications) × 100, rolling 30 дней |
| **Бейджи** | >70%: "Tez javob beradi" (зелёный), 40-70%: без бейджа, <40%: "Sekin javob beradi" (серый предупреждение) |
| **Влияние на ранжирование** | +10% к позиции в поиске для >70% |
| **Отображение** | Dashboard работодателя, публичный профиль компании, карточка вакансии |
| **Обоснование** | HH.uz "Индекс вежливости: 21%". Кандидаты уходят если нет ответа 48ч |
| **Ожидаемый результат** | +50% к response rate |

| **Лимит** | FREE: 2 автопоиска, STANDARD: 10, PREMIUM: unlimited |
| **Обоснование** | HH.uz "Автопоиск" — killer feature для проактивного recruiting |
| **Ожидаемый результат** | -60% времени на поиск |

| Параметр | Значение |
|----------|----------|
| **Описание** | Показатель количества подходящих кандидатов рядом с каждой вакансией |

| **Отображение** | В таблице вакансий: "458 nomzod" (кликабельно → поиск) |

### FR-05. Vacancy Bump (Поднять)
| Параметр | Значение |
|----------|----------|
| **Описание** | Обновление даты вакансии для подъёма в выдаче |
| **Бесплатно** | 1 раз в 7 дней per vacancy |
| **Платно** | 50,000 UZS за каждый дополнительный |
| **Эффект** | Вакансия получает updated_at = now() → поднимается в сортировке "по дате" |
| **Кнопка** | "⬆ Ko'tarish" (Поднять) рядом с вакансией |
| **Обоснование** | HH.uz "Поднять" — дешёвая альтернатива TOP |
| **Ожидаемый результат** | +20% к просмотрам при bump |

## 5. Технические рекомендации

### 5.1 Что НЕ нужно копировать у HH.uz
1. **Сложный UI** — HH.uz перегружен для blue-collar. Verifix Jobs должен быть проще
2. **Resume-first подход** — Blue-collar не заполняют полные резюме. Telegram profile достаточно
3. **Russian-only UX** — HH.uz в основном на русском. Verifix Jobs: uz-first + ru
4. **Desktop-first** — HH.uz оптимизирован для desktop. Verifix Jobs: mobile-first (Telegram + PWA)
5. **Keyword search** — HH.uz ищет по ключевым словам. Verifix Jobs: AI NLP + геолокация

### 5.2 Масштабируемость (уроки от HH.uz)

| Аспект | HH.uz (текущий) | Verifix Jobs (цель) |
|--------|-----------------|---------------------|
| База резюме | 6.5M | Phase 1: 5K → Phase 4: 500K |
| Вакансии | ~50,000 active | Phase 1: 200 → Phase 4: 15,000 |
| Пиковый поиск | ~10K QPS | Phase 4: 1K QPS |
| Отклики/день | ~100K | Phase 4: 10K |

### 5.3 Конкурентная стратегия vs HH.uz

HH.uz — генеральный job-портал. Verifix Jobs — специализированный для blue-collar.

**Где Verifix Jobs побеждает:**
1. **Telegram-native** — кандидат не выходит из Telegram (HH.uz: нужно ходить на сайт)
2. **Геолокация** — "работа рядом" по GPS (HH.uz: только текстовый регион)
3. **AI matching** — скоринг по данным (HH.uz: keyword search)
4. **Бенефиты** — visual benefits на карточках (HH.uz: только в тексте)
5. **Быстрая регистрация** — 5 шагов в Telegram bot (HH.uz: длинная форма резюме)
6. **MyID верификация** — государственная проверка (HH.uz: нет)
7. **Gov integration** — ARGOS/ish.mehnat.uz (HH.uz: нет)
8. **Реферальная система** — вирусный рост (HH.uz: нет)
9. **HRM bridge** — найм → онбоардинг → зарплата (HH.uz: нет)

**Где HH.uz побеждает (и как компенсировать):**
1. **База 6.5M** → Компенсация: импорт из ish.mehnat.uz + Telegram вирусный рост + Verifix HRM employees
2. **Brand awareness** → Компенсация: Telegram каналы + партнёрства с Verifix HRM клиентами
3. **Revenue** → Компенсация: пакетная монетизация + Employer Branding + TOP + HRM bundle
